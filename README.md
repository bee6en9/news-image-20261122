## How it is made

`main.ts` (Node 22, standard library only) draws `entry.png` (1024×1024) in code — flat vector illustrations, a 5×7 bitmap font, and a hand-written PNG encoder. Deterministic: two runs produce byte-identical output. No network, no external assets, no copied images.
